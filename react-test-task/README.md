# Тестовое задание: Конфигуратор товара

Данный проект представляет собой реализацию карточки товара с возможностью выбора цвета и размера, а также каталога товаров. Основной упор сделан на чистоту архитектуры, корректность потоков данных и удобство поддержки.  

## Архитектурный подход

Проект спроектирован с использованием методологии Feature-Sliced Design (FSD), что обеспечивает четкое разделение ответственности между логикой, представлением и данными. При реализации соблюдалась следующая иерархия приоритетов:

* **Границы (Boundaries)** выше зависимостей (Dependencies).  
* **Зависимости** выше потоков данных (Data Flow).  
* **Потоки данных** выше отдельных компонентов.  

Ключевые принципы:
* Применение минимального BDUF (Big Design Up Front) только к границам и инвариантам.  
* Соблюдение принципов KISS, YAGNI и бритвы Оккама для исключения избыточных абстракций.  
* Использование URL (searchParams) как единственного источника правды для состояния выбора товара, что обеспечивает корректную работу глубоких ссылок.
* Применение производного состояния (Derived State) для вычисления доступных опций, что повышает стабильность системы.  

## Технологический стек

* **React 19** (последняя стабильная версия).  
* **TypeScript** для обеспечения корректности и безопасности типов.  
* **Vite 8** для быстрой сборки и разработки.
* **Tailwind CSS v4** для декларативной стилизации.
* **React Router 7** для навигации и управления состоянием через URL.
* **TanStack Query (React Query)** для эффективной обработки серверного состояния и кэширования.  
* **Zustand** для управления глобальным состоянием корзины.  

## Ключевой функционал

* **Динамическая фильтрация**: список доступных размеров автоматически обновляется при смене выбранного цвета.
* **Deep Linking**: выбранные параметры (цвет и размер) сохраняются в адресной строке браузера. При обновлении страницы состояние полностью восстанавливается.
* **Оптимизация рендеринга**: использование React keys для автоматического сброса локального состояния галереи при смене контекста (цвета).
* **Валидация параметров**: система автоматически проверяет корректность данных из URL и сбрасывает невалидные или недоступные опции.  

## Установка и запуск

Для запуска проекта в локальном окружении выполните следующие действия:

1.  Установите зависимости:
    ```bash
    npm install
    ```

2.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```

Приложение будет доступно по адресу `http://localhost:5173`.
